# ShapeNet

Unzip `shapenet.zip` from the [Skeletons](https://drive.google.com/drive/folders/1YAVtLBOUctmh3xajZWAL-yXDgAx0G_vV?usp=drive_link) folder into `data/`, structured as follows:
```
data/shapenet/
├── ShapeNet/
│   ├── data-split/
│   ├── pointclouds/
│   └── synsetoffset2category.txt
├── ShapeNetMAT/
├── ShapeNetMesh/
├── ShapeNetSkel/
└── ShapeNetWatertight/
```

`ShapeNet/pointclouds` and `ShapeNet/data-split` are the `pointclouds` and `data-split` folders prepared by [Point2Skeleton](https://github.com/clinplayer/Point2Skeleton).
