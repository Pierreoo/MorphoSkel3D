# ModelNet

Unzip `modelnet.zip` from the [Skeletons](https://drive.google.com/drive/folders/1YAVtLBOUctmh3xajZWAL-yXDgAx0G_vV?usp=drive_link) folder into `data/`, structured as follows:
```
data/modelnet/
├── ModelNet/
├── ModelNetMesh/
└── ModelNetSkel/
```

`ModelNet` is the `modelnet40_normal_resampled` folder distributed by [PointNet++](https://github.com/charlesq34/pointnet2).
